# ACQUIRE Online v37

모바일 UI를 제약 없는 데스크톱 캔버스 방식으로 되돌린 버전입니다.

- 모바일 전용 Bottom Sheet/고정 액션바/원스크린 UI 제거
- PC 3열 레이아웃(플레이어 / 보드 / 주식)을 모바일에서도 그대로 유지
- 페이지 전체 가로·세로 스크롤 가능
- 게임 진입 시 가운데 보드 영역으로 한 번만 자동 가로 정렬
- 플레이어 현황은 왼쪽, 주식 거래소는 오른쪽으로 스크롤해서 확인
- 모바일에서 보드 높이가 0으로 접히던 과거 원스크린 CSS 잔여 규칙 제거
- 390×844 모바일 뷰포트 렌더링으로 보드 표시를 확인
- 기존 게임 규칙, 합병, BGM, 이모티콘, 턴 제한, SAFE, 이탈 자동 처리 등 유지

GitHub 저장소에 파일 전체를 덮어쓰고 Commit하면 Render가 자동 배포합니다.
