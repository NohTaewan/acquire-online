# ACQUIRE Online v8


휴대폰과 PC에서 같은 웹주소로 접속해 최대 6명이 플레이하는 온라인 ACQUIRE 스타일 보드게임입니다.

## v6에서 추가된 내용

- 7개 호텔 체인에 고유 색상과 로고 마크 적용
- 6명 플레이어별 프로필 색상/아바타 적용
- 게임 시작 시 짧은 도시 건설 인트로 애니메이션
- 최종 결과를 1~3위 포디움 + 전체 순위로 표시
- 우측 상단 `?` 버튼에서 핵심 규칙 확인
- 우측 상단 `⚙` 버튼에서 보드 크기, 도움말 표시, 애니메이션 줄이기 설정
- PC/휴대폰 반응형 UI 유지
- 방 생성/6자리 코드 참가/최대 6인/WebSocket 실시간 동기화 유지
- 체인 창립, 성장, 합병, 안전 체인, 주주 보너스, 매도/2:1 교환/보유, 주식 매수, 종료 정산 유지

## 로컬 실행

Node.js가 설치된 PC에서 폴더를 연 뒤:

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

같은 Wi-Fi의 휴대폰에서는 서버 PC의 로컬 IP를 이용해 `http://PC_IP:3000`으로 접속할 수 있습니다.

## Render 배포

이 폴더 전체를 GitHub 저장소에 올린 뒤 Render에서 **New → Blueprint**로 해당 저장소를 연결하면 `render.yaml` 설정으로 배포할 수 있습니다.

배포가 끝나면 생성된 `https://...onrender.com` 주소 하나를 참가자들과 공유하면 됩니다.

## 참고

현재 버전은 지인 플레이용 프로토타입입니다. 서버가 방과 게임 상태를 중계하지만, 모든 게임 규칙을 서버가 독립적으로 재검증하는 구조는 아닙니다. 공개 서비스로 운영하려면 서버 권한 검증, 영속 저장, 재접속 세션, 비정상 클라이언트 방어를 추가하는 것이 좋습니다.


## v8 추가 수정
- 내 타일의 배치 가능한 좌표를 현재 플레이어에게만 강조 표시
- 타일 위치 선택은 로컬 미리보기로 처리하며 `배치 확정` 전에는 다른 플레이어에게 전송하지 않음
- 보드의 내 타일 좌표를 직접 눌러 배치 가능
- 각 호텔 주식 재고를 `남은 주식 N / 25` 형식으로 표시
- 시작 순서 타일 선택 및 주식 거래 후 보충 타일 팝업 기능 유지


## v8 추가
- 손패의 영구 배치 불가 타일은 자기 타일 단계에서 폐기할 수 있습니다.
- 폐기를 확정하면 타일 행동을 사용한 것으로 처리되어 주식 매수 단계로 이동합니다.
- 폐기 좌표는 게임 상태에 저장되어 모든 플레이어의 보드에 `✕ 폐기`로 표시됩니다.
- 보충 후보에서 발견된 영구 배치 불가 타일도 공개 폐기되어 동일하게 보드에 표시됩니다.
