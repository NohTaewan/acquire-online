# ACQUIRE Online v11

휴대폰/PC에서 같은 웹주소로 접속해 최대 6명이 플레이하는 ACQUIRE 스타일 온라인 보드게임입니다.

## v10 변경 내용

- 모든 플레이어가 순서 결정 타일을 고르는 즉시 자동으로 본 게임 시작
- 방장이 게임 시작 전에 플레이어 턴 제한 시간을 설정
  - 30초 / 60초 / 90초 / 120초 / 150초 / 180초(3분)
- 턴 전체에 하나의 카운트다운 적용
- 시간 초과 시 게임이 멈추지 않도록 자동 진행
  - 타일 단계: 손패의 배치 가능한 타일 중 1장을 무작위 자동 배치
  - 영구 배치 불가 타일만 남는 경우: 무작위 1장 자동 폐기
  - 체인 창립/합병의 필수 선택이 남아 있으면 자동 선택
  - 합병 주식 결정이 남아 있으면 기본값인 전량 보유로 자동 처리
  - 주식 매수 단계: 선택 중인 주식도 취소하고 매수 없이 진행
  - 타일 뽑기 단계: 남은 타일 중 1장을 무작위 자동 뽑기
  - 이후 자동으로 다음 플레이어 턴 시작
- 화면 상단에 남은 턴 시간 표시, 마지막 10초 강조

## 기존 주요 기능

- 최대 6인 온라인 플레이
- 방 코드 참가 및 휴대폰/PC 동시 접속
- 전체 블라인드 타일 더미에서 순서 타일/보충 타일 선택
- 체인 창립·성장·합병·안전 체인
- 최대주주/2대주주 보너스 및 효과
- 호텔당 주식 25장 재고 표시
- 영구 배치 불가 타일 폐기 및 보드 공개 표시
- 클래식 주가표 팝업
- 공개 게임 이력

## v11 주주 보너스 동률 처리

- 주주가 1명뿐: 최대주주 + 2대주주 보너스를 합산해 단독 지급
- 최대주주가 여러 명 동률: 최대주주 + 2대주주 보너스를 합쳐 동률 인원끼리 분배
- 최대주주 1명 + 2대주주 여러 명 동률: 최대주주 보너스는 단독 지급, 2대주주 보너스만 동률 인원끼리 분배
- 분배 금액은 클래식 규칙처럼 $100 단위로 올림
- 합병 보너스 팝업과 게임 기록에 지급 유형을 명확히 표시
