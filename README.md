# ACQUIRE Online v9

휴대폰과 PC에서 같은 웹주소로 접속해 최대 6명이 플레이하는 온라인 ACQUIRE 스타일 보드게임입니다.

## v9 변경 사항

- 게임 시작 순서 결정은 **뒤집힌 전체 타일 더미**에서 플레이어가 한 장씩 직접 뽑습니다.
- 순서 타일은 선택 전에는 좌표가 보이지 않으며, 모두 뽑은 뒤 한꺼번에 공개합니다.
- 순서는 `1A → 1B → … → 1I → 2A → … → 12I` 기준으로 정렬되며 플레이어 목록도 같은 순서로 바뀝니다.
- 주식 거래 후 보충 타일도 **남은 전체 타일 더미를 무작위로 섞어 뒷면으로 표시**하고 플레이어가 직접 한 장을 고릅니다.
- 보충 타일 좌표는 뽑은 플레이어에게만 공개되며 공개 게임 이력에는 좌표를 남기지 않습니다.
- 합병으로 최대주주/2대주주 보너스를 받으면 별도 **주주 보너스 효과**와 금액이 표시됩니다.
- 상단 `☷ 기록` 버튼으로 타일 배치, 체인 창립/성장/합병, 주식 매수, 보너스, 폐기 등의 전체 공개 이력을 볼 수 있습니다.
- 상단 `📊 주가표` 버튼으로 클래식 주가표를 게임 중 언제든 확인할 수 있습니다. 다른 선택 팝업이 떠 있어도 우측 상단의 주가표 단축 버튼으로 열 수 있습니다.
- 클래식 표에 맞게 호텔 가격 등급을 수정했습니다.
  - 색슨 / 타워: 2칸일 때 $200부터
  - 아메리칸 / 페스티벌 / 월드와이드: 2칸일 때 $300부터
  - 콘티넨탈 / 임페리얼: 2칸일 때 $400부터
- 각 호텔 주식은 총 25장이며 거래소에 `남은 주식 N / 25`로 표시됩니다.
- 자신의 손패 중 영구적으로 놓을 수 없는 타일은 폐기할 수 있고, 폐기 좌표는 모든 플레이어의 보드에 `✕ 폐기`로 표시됩니다.
- 내 타일 위치 미리보기는 본인에게만 보이고 `배치 확정` 후에만 다른 플레이어 보드에 반영됩니다.

## 로컬 실행

Node.js가 설치된 PC에서 폴더를 연 뒤:

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## Render 배포

GitHub의 기존 `acquire-online` 저장소에서 v9의 파일들로 교체하고 Commit하면 Render의 Auto-Deploy가 켜져 있을 경우 자동으로 새 버전이 배포됩니다.

새로 배포하는 경우 이 폴더 전체를 GitHub 저장소에 올린 뒤 Render에서 **New → Blueprint**로 저장소를 연결하면 됩니다.

## 참고

현재 버전은 지인 플레이용 프로토타입입니다. 서버가 방과 게임 상태를 중계하지만 모든 게임 규칙을 서버에서 독립적으로 재검증하는 완전한 서버 권한 구조는 아닙니다. 공개 서비스로 운영하려면 서버 권한 검증, 영속 저장, 재접속 세션, 비정상 클라이언트 방어를 추가하는 것이 좋습니다.
