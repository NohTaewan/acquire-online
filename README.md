# ACQUIRE Online v22

휴대폰/PC에서 같은 웹주소로 접속해 최대 6명이 플레이하는 ACQUIRE 스타일 온라인 보드게임입니다.

## v14 · 플레이어 이탈/재접속 처리

- 플레이어 연결이 끊기면 **30초 재접속 유예**를 제공합니다.
- 재접속 유예 중에는 해당 플레이어의 턴 타이머가 `일시정지`로 표시되며, 30초 안에 돌아오면 이어서 진행합니다.
- **순서 결정 타일을 뽑는 중** 연결이 끊긴 플레이어가 30초 안에 돌아오지 않으면 자동으로 순서 결정에서 제외됩니다.
  - 이미 뽑은 순서 타일은 다시 타일 더미로 돌아갑니다.
  - 남은 플레이어가 모두 뽑았다면 즉시 순서를 정하고 자동으로 게임을 시작합니다.
  - 남은 플레이어가 1명뿐이면 게임 시작을 취소하고 대기실로 돌아갑니다.
- **본 게임 중** 30초 안에 돌아오지 않으면 해당 플레이어는 `자동 진행` 상태가 됩니다.
  - 손패에서 배치 가능한 타일 1장을 무작위로 배치합니다.
  - 영구 배치 불가 타일만 있으면 무작위 1장을 폐기합니다.
  - 주식은 구매하지 않습니다.
  - 보충 타일은 자동으로 1장 뽑습니다.
  - 합병 선택이 필요하면 자동 선택하며, 이탈한 주주의 합병 주식은 전량 보유로 처리합니다.
- 플레이어가 **방 나가기**를 직접 누르면 30초 대기 없이 즉시 자동 진행 상태로 전환됩니다.
- 게임 중 나간 플레이어의 현금·주식·손패는 삭제하지 않아 최대주주/주식 재고가 갑자기 바뀌지 않습니다.
- 플레이어 카드에서 `접속 / 재접속 N초 / 자동 진행 / 나감 · 자동 진행` 상태를 확인할 수 있습니다.
- 방장이 이탈하면 연결된 다른 플레이어에게 방장 권한이 자동으로 넘어갑니다.

## 기존 주요 기능

- 최대 6인 온라인 플레이 및 6자리 방 코드 참가
- 휴대폰/PC 동시 접속
- 전체 블라인드 타일 더미에서 순서 타일/보충 타일 선택
- 순서 결정 완료 후 자동 게임 시작
- 턴 제한: 무제한 / 30초 단위 / 최대 3분
- 타일 배치·체인 창립·성장·합병·안전 체인
- 최대주주/2대주주 보너스 및 동률/단독 주주 처리
- 호텔당 주식 25장 재고 표시
- 영구 배치 불가 타일 폐기 및 보드 공개 표시
- 클래식 주가표 팝업
- 공개 게임 이력
- Tower 전용 아르데코 호텔 엠블럼

## Render 업데이트

기존 GitHub `acquire-online` 저장소에서 이 폴더의 파일들을 기존 파일 위에 업로드하고 Commit하면, Render Auto-Deploy가 켜져 있는 경우 기존 웹주소에 자동으로 v22가 배포됩니다.


## v17 추가 사항
- 11칸 이상인 안전 체인은 보드의 각 호텔 타일에 작은 방패 형태의 `SAFE` 배지가 표시됩니다.
- 안전 체인 타일에는 은은한 청록색 외곽 강조도 함께 표시됩니다.

## v18 변경사항
- 게임 종료 결과 화면에 플레이어별 상세 정산 패널 추가
- 호텔별 최대/2대주주 보너스, 활성 호텔 보유 주식 매도, 가치 0 주식, 정산 전 현금과 최종 자산을 표시
- PC에서는 순위 옆에, 모바일에서는 순위 아래에 정산 결과가 표시됩니다.

## v19 변경사항
- 합병 시 주주 보너스 지급 애니메이션과 합병 요약을 **합쳐서 총 4초** 표시합니다.
- 4초 동안 소멸/존속 호텔, 최대주주·2대주주 기본 보너스, 실제 지급 대상과 금액을 보여줍니다.
- 보너스를 받은 플레이어 카드의 현금이 숫자 카운트업으로 증가하고 +지급액 효과가 표시됩니다.
- 4초가 끝나면 플레이어 순서대로 소멸 호텔 주식의 매도/2:1 교환/보유 결정을 시작합니다.
- 합병 요약 4초는 턴 제한 시간에서 차감하지 않습니다.


## v20 소셜 이모티콘
- 게임 중 자신의 플레이어 카드를 누르면 인사/감사/놀람/도발/선동 말풍선을 선택할 수 있습니다.
- 말풍선은 모든 참가자에게 약 3초간 표시됩니다.
- 선동 문구에는 `어서 타요! 🚌`, `합병 버스 출발! 🚌💨` 등이 포함됩니다.
- 합병 최대주주/2대주주, 합병 참여, SAFE 달성 같은 상황에서는 약 4초간 상황형 빠른 리액션 버튼이 제안됩니다.
- 이모티콘은 게임 상태 동기화와 분리된 WebSocket 메시지로 전달해 게임 진행 상태를 덮어쓰지 않도록 했습니다.

## v21 업데이트
- 이모티콘 선택 UI를 2단계 구조로 변경했습니다.
  - 1단계 대항목: 인사 / 감사 / 놀람 / 도발 / 선동
  - 2단계 소항목: 선택한 대항목의 문구만 표시
- 소항목 화면에서 `← 대항목` 버튼으로 다시 대항목 선택 화면으로 돌아갈 수 있습니다.
- 이모티콘 창 하단에 `취소` 버튼을 추가했습니다.
- 우측 상단 X 버튼으로도 즉시 닫을 수 있습니다.
- 모바일에서는 대항목/소항목 버튼이 화면 폭에 맞춰 자동 재배치됩니다.
